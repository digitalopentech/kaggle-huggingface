# 🤗 Neurociência com o ecossistema Hugging Face

Quatro atos usando o stack HF aplicado à neurociência: o Hub como catálogo (`huggingface_hub`),
EEG clínico real do CHB-MIT com visualização de uma crise epiléptica (`hf_hub_download` + `mne`),
embeddings do foundation model **EEGPT** (`braindecode` + `torch`), e modelos de linguagem
biomédica (`transformers` fill-mask + `sentence-transformers`).

- **Página renderizada**: aba *App*
- **Notebook executável**: [`neurociencia-huggingface.ipynb`](./neurociencia-huggingface.ipynb) — badge "Abrir no Colab" no topo
